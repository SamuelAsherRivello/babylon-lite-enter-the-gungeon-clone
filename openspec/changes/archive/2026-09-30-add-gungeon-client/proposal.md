# Proposal
## Why
The released authoritative dungeon server needs a playable, original landscape frontend and a verified public demo.
## What Changes
- Build Enter the Gungeon Clone as a 1–4-player cooperative wave arena.
- Add coded admission, readiness, weapons, upgrades, local pause, input recovery and touch controls.
- Render original pixel art, feedback and interpolated peers with Babylon Lite/WebGPU.
- Document and release on GitHub Pages, testing two public browser clients.
## Capabilities
### New Capabilities
- `gungeon-client`: Landscape cooperative dungeon frontend and public delivery.
### Modified Capabilities
None.
## Impact
Application, build/test configuration, README, release/Pages workflows. Shared server 0.7.0 is verified separately.
